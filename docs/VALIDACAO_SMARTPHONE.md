# Checklist de validação em smartphone — v2.1

Marcar o resultado em ao menos um Android Chrome e, se disponível, iPhone Safari. Testar pela URL **HTTPS** publicada, preferencialmente com rede Wi-Fi e depois dados móveis.

| Teste | Esperado | Resultado |
|---|---|---|
| 1. Carregar URL publicada | Cabeçalho, instruções e controles visíveis | [ ] |
| 2. Ativar RA e conceder permissão | Vídeo começa e aparece “PROCURANDO A MÃO” | [ ] |
| 3. Abrir mão no centro do vídeo | Aparecem **quatro modelos**: H₂SO₄, NaOH, Na₂SO₄, H₂O | [ ] |
| 4. Movimentar a mão | Modelos acompanham os dedos sem tremor excessivo | [ ] |
| 5. Retirar a mão | Aguardam novo rastreamento | [ ] |
| 6. Trocar câmera | Frontal espelhada / traseira não espelhada | [ ] |
| 7. + no NaOH uma vez | NaOH = 2; modelo NaOH destacado; equação acompanha | [ ] |
| 8. + na H₂O uma vez | H₂O = 2 | [ ] |
| 9. Verificar em 1,2,1,2 | Resultado correto; 4 elementos conservados | [ ] |
| 10. Recomeçar e verificar 1,1,1,1 | Resultado incorreto; H e Na desbalanceados; O e S conservados | [ ] |
| 11. Demonstração sem câmera | Quatro estruturas continuam visíveis; câmera desliga | [ ] |
| 12. Negar permissão | Mensagem orienta usar demonstração | [ ] |
| 13. Girar smartphone | Tela ajusta sem impedir o toque nos controles | [ ] |
| 14. Toque em um dos quatro modelos | Nome do composto aparece e o modelo recebe destaque | [ ] |
| 15. Alternar para outro app e voltar | Captura e interface permanecem estáveis | [ ] |

Registre marca/modelo do telefone, versão do sistema, navegador, iluminação, tempo para aquisição da mão e observações. Em dispositivos antigos, o carregamento de MediaPipe pode ser mais lento, e o modo demonstração é a alternativa.

**Não houve teste físico de câmera no ambiente de criação deste pacote.**
